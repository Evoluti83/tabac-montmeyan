# Site du Tabac de Montmeyan

## Description
Site web pour le tabac de Montmeyan.

## Prérequis
- Git installé
- VS Code installé
- Node.js (version 16 ou supérieure)

## Installation

### 1. Cloner le repository
```bash
git clone [URL_DU_REPO]
cd tabac-montmeyan
```

### 2. Extensions VS Code recommandées
Au premier ouverture du projet dans VS Code, vous serez invité à installer les extensions recommandées. Acceptez pour une meilleure expérience de développement.

### 3. Installer les dépendances
```bash
npm install
```

## Structure du projet
```
tabac-montmeyan/
```
